Set up AWS credentials for commands and tunnels that run inside the Chekov container.

How to use it:
- Copy your AWS credential setup command, then choose Save from clipboard. To enter it yourself, choose Enter credentials manually and then Save.
- The command must begin with "aws configure". Chekov runs it in the container, not on your host computer.
- Chekov checks the discovered credential profiles with AWS STS. The command output and any errors appear on this page; profiles whose credentials fail validation are removed from the credentials file.
- After setup, select a validated profile on the Tunnels, Local shell, Bastion shell, or Command Generator page.

The selected profile must be authorized for the AWS operations you intend to run. STS validation requires network access to AWS. Do not copy host-machine credentials into this container unless that is intended for your environment.
