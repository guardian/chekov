The home page lists the hostnames Chekov currently routes and a short description of each service.

How to use it:
- Select an endpoint to open that service in a new tab.
- Connectivity is checked from inside Chekov against each backend. The check runs about every 15 seconds and has a three-second timeout.
- "Responding - HTTP ..." means the backend returned an HTTP response; even a 4xx or 5xx response is not a health check. DNS, connection, timeout, and TLS failures are shown separately.
- Routes sharing the same backend share a check. A stopped or failed tunnel is shown as inactive and is not probed or started automatically.
- Routing configuration errors appear above the endpoint list. Connectivity checks do not test whether your browser can reach Chekov.

For missing routes or other discovery details, use the Debug page. Use Logs to investigate startup and configuration errors; the generated Nginx config links show what Chekov is currently serving.
