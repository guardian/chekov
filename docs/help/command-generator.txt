Build a copy-ready Docker command for running one of Chekov's shell tools inside a container.

How to use it:
- Choose the target container, execution user, command, profile, and region. Add Stack, Stage, and App when the selected tool connects to a remote EC2 instance.
- "shell" runs Chekov's SSM shell helper; it finds a running EC2 instance by App, Stack, and Stage tags and opens an interactive SSM session.
- "bash" opens Bash inside the selected container and sets AWS_PROFILE and AWS_REGION. These fields use the generator defaults when left blank.
- "host-tunnel" starts SSM port forwarding to the specified ALB. Supply the ALB, local port, and tunnel name as well as the target metadata.
- Copy the generated command and run it in a terminal that has Docker access.

The selected container must be running and contain the requested helper. AWS profiles and permissions must be configured inside that container; the generator does not copy credentials from your host.
