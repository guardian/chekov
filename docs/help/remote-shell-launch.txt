Choose the AWS profile, region, and EC2 tags used to locate a remote instance, then open an interactive SSM shell in a new tab.

How to use it:
- Select a validated AWS profile and the region containing the instance.
- Enter the instance's App, Stack, and Stage tag values. All three are required.
- Click Open bastion shell in new tab. Chekov selects the most recently launched running instance matching those tags.

The AWS identity must be allowed to describe instances and start an SSM session, and the target must be managed by Systems Manager. If no instance is found, check the profile, region, exact tag values, and instance state.
