Create and manage local routes to remote services by forwarding a local port through an AWS Systems Manager (SSM) session.

How to use it:
- Enter a tunnel name, AWS profile and region, Stack, Stage, App, and ALB. Stack, Stage, and App identify a running EC2 instance; the ALB is the remote host reached through it.
- The name becomes the tunnel hostname. If left blank, the ALB value is used as the name.
- HTTPS upstream and certificate verification are enabled by default. Disable either only when the target requires it.
- Create tunnel starts the host-tunnel command and adds its local endpoint to Chekov's routes. Use Start, Stop, or Delete to manage it later.
- Check the Status and Output columns for tunnel startup or exit details. A stopped or failed tunnel is not reachable until it is started successfully.

The selected AWS profile must be available in Chekov and authorized to discover the matching EC2 instance and start an SSM port-forwarding session. The instance must be running, have the matching App, Stack, and Stage tags, and be managed by Systems Manager. Configure credentials on the AWS credentials page first.
