Choose an AWS profile and region, then open an interactive Bash shell inside the Chekov container in a new tab.

The selected profile and region are exported as AWS_PROFILE, AWS_REGION, and AWS_DEFAULT_REGION for commands you run in the shell. The profile's credentials must already be configured inside Chekov; set them up on the AWS credentials page first.

This is a local container shell, not a shell on a remote EC2 instance. Use Bastion shell for an SSM session on a matching running instance.
