This is an interactive shell on a running EC2 instance, opened through AWS Systems Manager (SSM) from the Chekov container.

The instance is selected by its App, Stack, and Stage tags. If more than one running instance matches, Chekov connects to the most recently launched one.

The selected AWS profile must be valid and allowed to describe EC2 instances and start an SSM session. The target instance must be connected to Systems Manager and permit session access. If connection setup fails, check the selected profile and region, the instance tags and SSM status, and the Logs page.

The browser session closes after 10 minutes without terminal activity. Reopen the Bastion shell page to start a new session.
