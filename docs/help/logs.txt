This page shows recent Chekov application log lines, with the newest lines first. It displays 50 lines by default; add ?count=100 to the URL to request a different number, up to 200.

Use the logs to investigate route discovery, Nginx configuration or reload errors, AWS profile validation, and tunnel or SSM startup failures. The output is diagnostic: use the Debug page for container discovery details and the generated-config links to inspect active routing.
